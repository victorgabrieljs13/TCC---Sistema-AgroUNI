# Sistema de Gestão para Feirantes - AgroUNI

Sistema de gerenciamento de estoque para feirantes da central de abastecimento, 
permitindo controle de produtos, preços e movimentação de estoque em tempo real.

## Tecnologias utilizadas
- Back-end: Node.js, Express
- Banco de dados: MySQL (Aiven)
- Front-end: HTML, CSS, JavaScript (em desenvolvimento)
